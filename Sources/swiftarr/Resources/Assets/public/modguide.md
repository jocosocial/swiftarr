## Twit-arr Moderator Guide

Thank you for volunteering as a moderator for Twit-arr\! Your role is crucial in maintaining a positive and engaging community environment. Here's a detailed overview to help you get started:

## Getting Started

Create your account using the provided Registration Code. If you want a separate account to use when moderating, create that as well. Creating a separate account is only supported on board and not during the pre-embarkation registration period.

Next, have your access level upgraded to Moderator by someone with THO or TwitarrTeam access. If you pre-register your account, please let Thera know what your handle is, and that can be set in advance. If not, please message @twitarrteam once you’re onboard to get that updated. 

## Twit-arr Concepts

### Users

Everyone who wants to use Twit-arr needs to register their account with a code provided by JoCo Cruise. This code links multiple accounts under a single user. Registration Codes are emailed to attendees a few weeks before sailing and can also be obtained at the Info Desk.

People can create multiple accounts linked to one Registration Code. If you set a user's access level to Quarantined (temporarily or permanently), all accounts associated with that user's Registration Code will be affected for the duration of the quarantine.

### Content Types

Users can create and manage several types of publicly viewable content, all of which can be reported and moderated:

1. **Forum Threads and Posts**
    * **Forum Threads**: Titles of forums and the posts within them.
    * **Posts**: Content shared within forum threads.  
2. **Looking For Group (LFG)**
    * **LFG Posts**: Titles, information, location text, and posts within LFG chats.
3. **User Profiles**
    * **Profile Fields**: Information such as Home Town or Cabin Number.
4. **Seamails**
    * **Private Conversations**: Messages between users. Moderators cannot view Closed Seamails at all or Open Seamails unless a report has been made.
5. **Photostream**
    * **Images**: Images posted to the photo stream.

Users can create, edit, and delete their content. All changes are tracked, allowing moderators to view edit histories. In the case of the photostream, users cannot modify or delete images they share. Users can file reports on the content that others create, but cannot report other users directly. Moderators can delete images only.

## Moderator Tools

### Platform Support

The Web UI (twitarr.com) and the Android/iPhone App (Tricordarr) support moderator activities and user reports. The iPhone app (Kraken) does not support moderator activities but does support user reports.

### The @moderator User

There is an account with the handle ***@moderator***. This account can interact like all other users by posting, commenting, and sending and receiving Seamail. It can also be used to publicly address issues by selecting *Post as Moderator*.

![The post as moderator checkbox](/img/modguide/image0.png)

**Please remember to check the *Post as Moderator* box for every post you want to make as** **@Moderator.**

You can begin a Seamail chat with a user while posting as @Moderator, and then follow up with a chat message from your own account. Likewise, you can create a Forum Thread as a moderator by selecting *Post as Moderator*.

When users send Seamail to **@moderator** all mods are alerted and will be able to reply via Seamail using **@moderator**. In previous sailings, viewing a Seamail message to **@moderator** would mark it as viewed for all other moderators. Starting in 2026, this should no longer be the case, and viewing will be specific to you.

### Forums

#### Moderator Forums Categories

There are two forum categories that are accessible only to moderators. The first category, *Moderators Only*, serves as a space for moderators to discuss moderation activities, ask questions, and raise issues that need to be addressed by the team. This space is also viewable by the TwitarrTeam and can be used for platform questions.

The second category, *Mods Only Dumpster Fire*, is specifically designed for relocating problematic forum threads to a place where regular users cannot view them.

#### Pinned Forum Threads and Posts

Users with Moderator access (THO, TwitarrTeam, Moderator) can pin a thread to a category. This should be used sparingly and only to highlight a limited number of threads. The pinned forum thread continues to show in the regular thread list. During the first two days, you can expect a lot of requests for mods to pin threads. 

Posts within a thread can be pinned by the thread creator or by users with Moderator access (THO, TwitarrTeam, Moderator). To pin a post, simply tap on the post and select "Pin." Pinned posts will appear at the top of every page of forum posts and in the list. Please use this feature sparingly. You can also unpin a post by tapping the "Pin" button at the top of the screen in the thread.

## Reports

Users can report content they think moderators should take a look at, and they may occasionally report the wrong thing. Most often, this will be users reporting a forum when they mean to report a post within that forum. Users can’t directly report other users—they can only report content other users have created.

When a user files a report, moderators receive a notification and can view the report and the reported content (post, picture, seamail, or user profile). Mods can also moderate content by tapping the *Mod* button next to it. Only Moderators will see this button. The *Mod* button opens a page showing the content, all previous edits to it, user reports against it, and options for performing moderation actions on the post in question.

### Moderation Actions

#### Handling Reports

Reports show up in the *Moderator Pages* section of the web client. To find it, tap on the Twit-arr header to open the menu, and the Moderator Pages option should be there if you have Moderator access. Inside Moderator Pages is a page that lets you view open user reports.

When viewing reports from multiple users on the same piece of content please click *Start Handling All* to mark the reports as in-process by you. This lets other mods know which reports are being handled and which are not yet handled. You can then edit the content, delete the content, quarantine the content, give the user a timeout, or take no action at all. You should hit the *Close All* button when you’re done so the user reports will be marked as having been dealt with.

#### Content

The Moderation page for all types of content is essentially the same and allows you to take the following actions:

* **Edit:** Lets the moderator modify the content, changing text and removing images.   
* **Delete:** Removes the content entirely. If you do this for a Forum or a LFG, all the posts within it are also removed. For forums, it may be preferable to move the forum into a Moderator-only category, depending on the content and tone of the conversation. User Profiles can’t be deleted—a user always has exactly one profile.  
* **Lock:** If a Forum or LFG is locked users won’t be able to add new posts there.  
* **Quarantine:** Setting the Quarantine state on content changes its text to *Under Moderator Review* and removes images for all non-moderators. The mods can then discuss what to do in the moderator forums, finish eating lunch, or get some sleep. Removing Quarantine (setting state back to *Normal*) returns the content to its original state.  
* **Moderator Reviewed:** This means you’ve looked at the content and determined you need to take no action. See the section on Auto-Quarantine for more on why this option is useful.  
* **Moderate User:** If you want to moderate the user instead of the content, this will take you to the User Moderation page.

#### Users

The User Moderation page shows the user’s primary account, any sub-accounts, and all reports against content the user has created on any of their accounts.

The following actions are available to moderate the user:

* **Quarantine User:** A Quarantined user is unable to create or modify content. This means they cannot post, create forums, edit or delete their posts, create LFGs or post in them, or edit their profile.  
* **Temp Quarantine:** Same as Quarantine, but only lasts for a number of hours that you select to allow time for mod review/discussion. This should be communicated via seamail to the user who will be quarantined.   
* **Un-Quarantine:** Returns the user’s accounts to a normal state, so they can post again.  
* **Ban:** Only THO-level users have this option. Prevents the user from logging in with any of their accounts, which in turn means they cannot see any user-generated content. The home page (announcements and Daily Theme) and the Schedule are still accessible while logged out. If you think a user should be banned, open a thread about it in the Moderator Forum.

Step-by-step instructions with screenshots are available at the end of this document. 

### Auto-Quarantine

When multiple users report the same piece of content, that content may be automatically quarantined. Auto-quarantine functions similarly to a quarantine issued by moderators: the text of the content is replaced with *Under Moderator Review*, and all images are removed. This feature is designed to help manage issues that arise when moderators are unavailable, such as during late-night hours.

By definition, content that is auto-quarantined will have received numerous reports. When you access the moderation page for this content, you will find that its Moderation State is set to *auto-quarantined*. You should change the content’s state (even to *quarantined*) before closing any open reports.

If the reported content does not appear to be offensive (and be sure to check the previous edits), it's possible that a group of users has coordinated a 'brigade' to report the non-offensive content intentionally in order to trigger an auto-quarantine. In this situation, you can set the content to *Moderator Reviewed*. Content marked as *Moderator Reviewed* is protected from being auto-quarantined.

## Step-by-Step Moderation with Screenshots

1. **Access Moderation Page**  
   * Tap the “Mod” button on the content or a report to open the moderation page.  
2. **Perform Actions**  
   * **Edit**: Modify content as needed.  
   * **Delete**: Remove content entirely.  
   * **Change Category**: For forums, move threads to appropriate categories.  
   * **Set State**: Use “Quarantine” or “Lock” options as necessary.  
   * **Mod User**: Navigate to User Moderation for user-specific actions.  
   * **View In Context**: See related posts to understand the full context.  
3. **Handling Reports**  
   * **Start Handling All**: Begin addressing reports.  
   * **Close All**: Mark reports as resolved once you’ve finished.

From here, you can perform several moderation actions:

**Edit Content**

* Tap the **Edit** button to open the “Mod Edit” page. This page functions similarly to the regular edit page but will display “Mod Edit” in the upper left corner to indicate you’re using moderation powers. Here, you can update the text and remove any attached photos. Once you’ve made your changes, tap **Post** to save them.  

**Delete Content**

* To remove the content entirely, tap the **Delete** button. Confirm the deletion by tapping **Delete** in the dialog box that appears. This is the only action available to Photostream images.

**Change Category (Forum Threads)**

* For forum threads, use the **Change Category** dropdown button. Select a new category from the list to move the forum to a more appropriate location.

**Set Content State**

* Use the **Set State** dropdown menu to either **Quarantine** or **Lock** the content. The current moderation status is displayed to the right of the dropdown menu.  
  * **Quarantine**: Hides the content from non-moderators and changes its status to “Under Moderator Review.”  
  * **Lock**: Prevents the author from making further edits.

**Mod User**

* Tap the **Mod User** button to access the User Moderation page. Here, you can manage actions related to the user rather than the content they posted.

**View In Context**

* Use the **View In Context** button to navigate to the page containing the relevant forum post, LFG post, or profile. This helps you understand the surrounding context and identify any other posts that may need moderation.

**Start Handling All**

* The **Start Handling All** button marks all reports related to this content as “being handled” by you. This step is optional but can help inform other moderators that you are currently reviewing the content.  

**Close All**

* Once you’ve completed your review and actions on a piece of content with open reports, tap the **Close All** button. This updates the status of the reports to indicate that they have been addressed, preventing other moderators from assuming further action is needed.

**User Moderation Actions:**

![The User Moderation Page](/img/modguide/image3.png)

*The User Moderation Page*

On the User Moderation page, you can manage both the user and any associated alternate accounts. Here’s how to use the available tools:

1. **View Alternate Accounts**  
   * If the user has alternate accounts, their names will be displayed on this page. You can also view all reports related to content created by this user or their alternate accounts.  
2. **Set Access Level**  
   * **Changing Access Level**: Adjust the user’s ability to create and modify content by setting their access level. As a moderator, you can choose between:  
     * **Quarantined**: This status prevents the user from posting new content, editing existing content, or modifying their profile.  
     * **Verified**: This status allows the user to fully participate, including posting and editing content.  
   * **Check Current Access Level**: Before making changes, verify the user’s current access level to ensure that the modification is appropriate.  
3. **Temporary Quarantine**  
   * **Setting Temporary Quarantine**: To impose a temporary restriction, specify the number of hours the user should be prevented from posting or modifying content. Tap the **Start Quarantine** button to activate this state. During this period, the user will be unable to:  
     * Create new posts  
     * Edit existing posts  
     * Modify their profile

By using these moderation tools effectively, you can manage user behavior and ensure that the community remains positive and engaged.
